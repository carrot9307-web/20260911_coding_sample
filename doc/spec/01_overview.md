# 系統規格規格書 — 第一章：專案概述 (System Overview)

## 1.1 系統簡介
本系統為一套結合 **看板式任務管理 (Kanban Board)** 與 **RFI (Request for Information) 請示追蹤機制** 的現代化專案協作平台。設計風格採用尊貴典雅的 **Art Deco (蓋茨比風 / Gatsby Edition)**，視覺上以深色背景 (#0A0A0A) 搭配奢華金 (#D4AF37) 與幾何線條呈獻極致質感。

## 1.2 核心目標
- **高效率任務管理**：提供多欄位看板、拖曳排序、任務狀態追蹤與甘特圖 (Gantt Chart) 時程檢視。
- **嚴謹 RFI 流程**：支援合約/施工/技術請示單據建立、答覆審核與一鍵轉化為執行任務。
- **全功能模擬主機**：前端內建完整 AppContext 狀態機制與 API 測試控制台，無須複雜後端資料庫即可完整示範全套業務流程。
- **本地開箱即用**：提供獨立執行的單機環境與一鍵式伺服器啟動/關閉腳本。
